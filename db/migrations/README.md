Особенности:
- внутренние PK/FK: bigint GENERATED BY DEFAULT AS IDENTITY;
- soft delete через deleted_at;
- уникальность при soft delete через partial unique indexes;
- updated_at обновляется триггером touch_updated_at;
- типы/статусы в MVP реализованы через CHECK constraints, без справочников;
- uploaded resumes и parsed drafts оставлены как одна из ключевых фич WorkNet.
